# Introduction to AI-Assisted Programming

This material forms the basis for an introductory course on the use of large language models (LLMs) and agents in computer programming tasks.

In this course open-weights models running in College owned infrastructure are used, illustrating the possibility of harnessing the potential of LLM assisted workflows without relinquishing autonomy, control and, importantly, data to external commercial providers.

The course material is based on the work of [Chris Cooling](https://profiles.imperial.ac.uk/c.cooling10) at the Early Career Research Institute at Imperial College London.
